# Real-time-strategy-game

An offline, turn-based, modern-era grand strategy game for phones (working title). Every country in the world is AI-controlled; you pick one. War, economy, resources, diplomacy, technology and government all feed each other, so every success creates a new problem.

**Status:** Phase 0 — design documents written, awaiting approval. There is no playable build yet.

- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — how it will be built
- [docs/DATA_SCHEMAS.md](docs/DATA_SCHEMAS.md) — JSON formats for countries, regions, resources, governments and more
- [docs/RISKS_AND_QUESTIONS.md](docs/RISKS_AND_QUESTIONS.md) — decisions needed and the risk register
- [CLAUDE.md](CLAUDE.md) — working rules and current status for Claude Code sessions

## Plan

Built phase by phase, each one playable and deployed: setup → Middle East MVP → war depth and governments → diplomacy → technology → the whole world → replayability → polish. See GAME_DESIGN.md §12.
